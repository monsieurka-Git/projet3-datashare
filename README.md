# 📘 DataShare — Documentation du projet

Bienvenue sur le dépôt **DataShare**, projet de partage de fichiers temporaire développé dans le cadre de la formation OpenClassrooms.

Ce dépôt contient le code source complet du projet (backend Spring Boot, frontend Angular, base PostgreSQL) ainsi que les livrables techniques.

---

## 🌐 Documentation en ligne

La documentation complète du projet est disponible ici :

👉 [https://monsieurka-git.github.io/projet3-datashare/](https://monsieurka-git.github.io/projet3-datashare/)

Elle présente :
- L’architecture du projet  
- Les tests backend et frontend  
- Les aspects sécurité, performance et maintenance  
- Le modèle de données et les choix techniques  

---

## 🛠️ Technologies principales

| Domaine | Stack utilisée |
|----------|----------------|
| **Frontend** | Angular, TypeScript, HTML, CSS |
| **Backend** | Spring Boot, Java |
| **Base de données** | PostgreSQL |
| **Tests** | Cypress, MockMvc |
| **Documentation** | MkDocs Material |
